# Handoff

The entry point for anyone or any agent picking this repository up. It holds no project facts, only
where they live.

1. `AGENTS.md`: the rules for every agent, the fork's identity, build and test commands, and where
   the important code is.
2. `Docs/Thesis/FORK_CHANGES.md`: every change made to the original OpenIntelligence code, with its
   open items.
3. `git log --oneline -15` and `git status`. Trust git over any document, this one included.
4. `Docs/Thesis/plans/`: approved plans waiting to be executed.
5. `Docs/ai/codemap/INDEX.md`: which files make up each feature.
